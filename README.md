# Yuvika V — Portfolio

A scrapbook, bullet-journal style portfolio for content creation and social media roles.

Plain HTML, CSS and JavaScript. There is no build step.

## Deploy on Vercel
1. Go to vercel.com and log in with GitHub.
2. Click **Add New → Project** and import `yuvikavarun/portfolio`.
3. Leave the framework as **Other**, with no build command and no output directory, then click **Deploy**.

## Edit content
Open `index.html` and find the block marked `EDIT THIS BLOCK` near the bottom. It holds the reel lists (`REELS`, `POSTS`), the graphic design cards (`DESIGNS`), the experience entries (`JOBS`) and the intro video (`INTRO`).

- Videos go in `reels/` (MP4, H.264, 720p keeps them light).
- Poster images go next to them, as `.jpg`.
- Design images go in `designs/`.
